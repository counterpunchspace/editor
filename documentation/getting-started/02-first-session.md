# Your first session

The first session is a reliable editing loop, not every panel at once: open a font, make a small visible edit, confirm it, and save. Once that loop feels familiar, the rest of the application is easier to learn.

Use Chrome if you can. See [Before you begin](00-before-you-begin.md) for browser and PWA notes.

Have a sample `.glyphs`, `.glyphspackage`, `.ufo`, `.designspace`, or `.babelfont` source ready if you want to save back to the same format. Counterpunch can also open `.vfj`, `.sfd` and `.ttf`; those open for editing but do not save in place yet.

1. Open Counterpunch. The launcher opens first. For work you want to keep, click **Open…** and pick a source on your disk; see [Fonts on this computer](../files/02-local-disk-access.md).
2. The font opens in its own window. When it loads, switch to the **Editor** with `Cmd/Ctrl+Shift+E`.
3. Pick a simple glyph such as H. Move one point a little and confirm the outline updates.
4. Save with `Cmd/Ctrl+S`. The font name in the toolbar shows a dot when there are unsaved changes.

![Font name and unsaved-change indicator in the toolbar](../files/images/save.png)

Keep the first edits small so you can tell whether the workflow is working. If a panel is unfamiliar, ignore it for now and come back via the [Workspace tour](03-workspace-tour.md).
