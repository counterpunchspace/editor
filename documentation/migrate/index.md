# Migrate from other editors

Counterpunch opens sources from other font editors, then lets you convert implicit conventions into Counterpunch's explicit model. Use **Font → Convert to Counterpunch** after opening a file when you want that migration. The dialog offers three independent options: rename glyphs to Counterpunch naming, mark components automatic where the engine already matches, and let Counterpunch generate your automatic OpenType features. Hover the info button on each option to preview the outcome.
