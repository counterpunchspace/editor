# Cuts modal design files

`cuts-branches-modal-v6.svg` is the finished mockup. It was drawn by hand as SVG. There is no generator script. Earlier drafts (v2 through v5) exist only as files in the Cursor project assets folder and are not the design to implement.

`branch-graph.ts` is a snapshot of the last runtime that tried to draw that mockup inside the editor. The live copy under `webapp/js/cuts/` was never committed and is gone from the working tree. This snapshot is not part of the build.
